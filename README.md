###**Overview**
Campus Management System is a simple Java console-based application used to manage student academic and support information. It allows users to manage student details, attendance, marks, and complaints in one system.
The project is developed using Core Java and stores data locally using file handling.

Features
Add, view, search, and delete students
Manage student attendance
Calculate attendance percentage and status
Enter and update student marks
Calculate average marks and grade
Submit and manage complaints
Update complaint status
Generate a complete student report
Save and load data using files
Input validation for incorrect values
Technologies / Tools Used
Programming Language: Java
Concepts: OOP, ArrayList, Exception Handling, File Handling
Storage: Java Serialization
IDE: IntelliJ IDEA / Eclipse / VS Code
JDK: Java 8 or above
Version Control: Git and GitHub

#Installation and Running
#Step 1: Install Java
Install JDK 8 or above on your computer.
Check Java installation using:
java -version
javac -version

#Step 2: Download the Project
Download or clone the project from GitHub.

#Step 3: Open the Project
Open the project folder in any Java IDE such as IntelliJ IDEA, Eclipse, or VS Code.

Step 4: Compile the Project
Open the terminal inside the project folder and run:
javac *.java

Step 5: Run the Project
java Main

The main menu will appear in the console.

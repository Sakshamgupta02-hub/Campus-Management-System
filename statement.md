# Campus Management System

## Problem Statement

Managing student details, attendance, marks, and complaints manually can be time-consuming and difficult to organize. This project provides a simple system to store and manage these records in one place.

## Scope of the Project

The system covers basic student management, attendance management, marks management, complaint management, and student report generation. Data is stored locally using Java file handling.

## Target Users

* College administrators
* Teachers/faculty members
* Students

## High-Level Features

* Add, view, search, and delete student records
* Add and update attendance
* Add and update marks
* Calculate attendance percentage and grades
* Submit and manage complaints
* Generate student reports
* Save and load data using local files
